# VanRakshak (वनरक्षक)

**VanRakshak** is an AI-powered autonomous drone patrolling system designed for forest monitoring, wildfire detection, illegal logging prevention, and wildlife protection.

## Overview

VanRakshak combines multi-drone swarm collaboration, real-time computer vision AI pipelines, and autonomous mission loops to provide scalable, low-cost forest conservation and perimeter surveillance solutions.
